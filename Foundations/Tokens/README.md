# Tokens

Source page: https://atlassian.design/foundations/tokens

This directory preserves the Atlassian Design token pages and the concrete token artifacts referenced by the token library. The all-token link on the Foundations page resolves to https://atlassian.design/components/tokens/all-tokens.

## Contents

- `Tokens.md`: Foundations/Tokens overview page notes.
- `Design-tokens-explained.md`: design token concepts and examples.
- `Use-tokens-in-code.md`: setup, `token()`, Babel plugin, codemod, and linting guidance.
- `Use-tokens-in-design.md`: design/Figma usage page notes.
- `Migrate-to-tokens.md`: migration page notes.
- `All-tokens.md`: full table of 558 tokens.
- `all-tokens.json`: complete token data extracted from `@atlaskit/tokens@15.5.0`.
- `all-tokens.csv`: spreadsheet-friendly token data.
- `source-pages/*.html`: raw HTML snapshots of every token-related source page.
- `atlaskit-tokens-15.5.0/`: exact unpacked npm package for `@atlaskit/tokens@15.5.0`, including generated code, Figma JSON exports, raw token maps, codemods, README, changelog, and license.

## Package source

The package version was resolved from the npm registry while importing these files. It matches the published `@atlaskit/tokens` package available at the time of capture.
