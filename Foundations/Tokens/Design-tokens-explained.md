# Design tokens explained

Source: https://atlassian.design/foundations/tokens/design-tokens

Design tokens are name and value pairings that represent small, repeatable design decisions for Atlassian app experiences.

Themes are collections of token values that make light mode, dark mode, high contrast, spacing, motion, shape, and typography variations possible.

Token names are described by foundation, property, and optional modifiers. The source page uses `color.icon.success` as an example token.

The page covers color, elevation, opacity, space, and typography token examples.

Raw HTML for this page is preserved at `source-pages/design-tokens-explained.html`.
