## Usage

# @atlaskit/design-system/no-empty-styled-expression

Forbids any styled expression to be used when passing empty arguments to styled.div() (or other JSX
elements).

This rule is maintained by another package and configured here; refer to
https://atlassian.design/components/eslint-plugin-design-system/no-empty-styled-expression/usage for
more details.
