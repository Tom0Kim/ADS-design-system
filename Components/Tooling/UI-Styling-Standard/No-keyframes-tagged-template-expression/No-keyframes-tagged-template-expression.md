## Usage

# @atlaskit/design-system/no-keyframes-tagged-template-expression

Disallows any `keyframes` tagged template expressions that originate from a CSS-in-JS library,
including `@atlaskit/css`, `@compiled/react`, Emotion, and `styled-components`.

This rule is maintained by another package and configured here; refer to
https://atlassian.design/components/eslint-plugin-design-system/no-keyframes-tagged-template-expression/usage
for more details.
