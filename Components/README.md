# Components

Components are reusable building blocks that meet specific interaction needs. They combine to create intuitive user experiences.

Source page: https://atlassian.design/components

## Archive contents

- Readable Markdown for component Examples, Code, Usage, props, migration, and supporting pages.
- Local image assets referenced by the documentation.
- React/TypeScript example source embedded in Markdown and retained under `_source`.
- Original Constellation MDX, package manifests, README files, changelogs, and licenses.
- `MANIFEST.json` with source routes, package versions, repository commit, and generated file paths.

## Conversion method

This archive follows the attached Foundations ZIP convention: one readable Markdown document per documentation page, local relative image links, and downloadable source artifacts retained beside the documentation. Components additionally require preservation of tabbed content and executable React examples, so their public MDX and TSX sources are included.
